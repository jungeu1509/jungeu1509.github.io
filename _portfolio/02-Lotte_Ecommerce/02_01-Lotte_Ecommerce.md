# 롯데 이커머스

롯데쇼핑 e커머스사업부 BO개발팀 (롯데ON)

주 업무 : 엘스탬프 및 이벤트의 백엔드, 프런트엔드 개발 및 운영

---

## 핵심 프로젝트

### 엘스탬프 교환소 시스템 — 아키텍처 설계부터 운영까지 전 단계 담당

> **엘스탬프(L.STAMP)**는 롯데ON의 그룹 간 Gateway 전략 핵심 앱테크 서비스. 롯데 온·오프라인 구매 및 다양한 미션 수행으로 스탬프를 적립하고 엘포인트·쿠폰으로 교환하는 리워드 서비스. 
> 2025년 3월 엘스탬프 2.0 리뉴얼 오픈 후 신규 이용자 수 전월 대비 2배 이상 증가(엘스탬프 사용자 - 회원수 약 1000만명, MAU 약 74만, DAU 약 8만), 평균 이용 일수 약 30% 증가. 오픈 이후 빠르게 안정화하여 큰 이슈 없이 안정적인 서비스 운영 중.

교환소는 엘스탬프 2.0 리뉴얼의 핵심 신기능. 스탬프를 소진하여 혜택을 획득하는 교환소 시스템을 요건 분석부터 DB 테이블 및 코드 아키텍처 설계, FO/BO API, 배치, 모니터링, 성능 개선까지 전 생애주기를 단독 담당.

**기간**: 2024년 12월 ~ 2025년 3월 리뉴얼 오픈 (오픈 후 개선 및 운영 작업 다수 진행)
**교환소 유형**: 랜덤교환소 (베팅 형태의 랜덤 혜택 교환 방식) / 정률교환소 (1:1 교환 방식)

#### 1단계 — 요건 분석 & DB 및 코드 아키텍처 설계

- 엘스탬프 리뉴얼 교환소 전체 요건 분석
- 교환소 핵심 테이블 설계 (신규 테이블 약 9종 설계)
  - 교환소 정보, 혜택 정보, 사용자 스탬프 소진 정보, 사용자 교환 이력, 타 MSA 혜택 요청 및 응답 등
- 교환소의 종류 및 혜택을 확장하고 싶은 기획팀의 니즈가 존재하여 다양한 디자인 패턴을 적용하여 아키텍처 설계
  - Strategy, Factory, Adapter, Template 등

#### 2단계 — 신규 개발

- **FO API 개발**: 교환소 목록 조회, 응모(교환), 당첨자 한마디 API
- **BO 어드민 개발**: 교환소 관리 화면, 정률교환소 현황 조회 탭, 랜덤교환소 현황 조회 탭
- **모니터링 및 대사 배치 개발**: 교환소 혜택 지급 현황 모니터링, 대사 배치 구축

#### 3단계 — 성능 개선

> 예산체크 API · 교환 API 집중 최적화로 간헐적 Timeout 완전 제거, **평균 응답속도 60% 향상**

- **정률교환소 스탬프 소진 로직 성능 개선**: 교환 처리 시 스탬프 소진 쿼리 최적화
- **교환된 엘포인트 예산 체크 로직 성능 개선**: 예산 초과 방어 체크 성능 개선
- **랜덤교환소 혜택 저장방식 개선**: 혜택 데이터 저장 방식 구조 개선
- **혜택별 당첨 개수 제한 로직 개선**: 동시성 환경에서의 당첨 개수 정합성 보장

#### 4단계 — 운영 고도화

- **혜택교환 재요청 처리 배치 고도화**: 외부 시스템 응답 지연/실패 시 재요청 대기 시간 파라미터화, 무응답·실패 건 자동 재처리 로직 강화
- **혜택 모니터링 개선**: 모니터링 시간·범위·종류 확대
- **회원 정보 조회방식 개선**: 멤버스 탈퇴 후 재가입 시 오프라인 회원번호 불일치 문제 해결 (회원 관리 테이블 조회 방식 전환)
- **미적립 포인트 연동 배치 수정**: 포인트 미적립 건 자동 연동 배치 오류 수정
- **중복교환 방어 로직 로그 개선**: 동시 교환 요청 차단 시 추적 가능한 로그 체계 구축
- **교환요청시간 저장 로직 개선**: Java/MySQL 나노초 처리 차이로 인한 교환 요청 시각 불일치 해결

#### 어필 포인트

- 설계 → 개발 → 성능 개선 → 운영 고도화까지 **전 생애주기를 단독 담당**한 경험
- 스탬프 소진, 예산 체크, 혜택 당첨 개수 제한 등 **금전적 정합성이 중요한 도메인**에서 동시성 제어 경험
- redis 및 쿼리최적화 등을 통한 예산체크·교환 API 최적화로 간헐적 발생하는 Timeout 완전 제거 및 **평균 응답속도 60% 향상** 달성
- 외부 시스템 연동 실패 시나리오에 대한 **모니터링 및 재처리 배치 개발** 
- 운영 중 회원 데이터 불일치 이슈 **근본 원인(탈퇴 후 재가입, 포인트 카드 변경 등)까지 추적**하여 해결. (회원번호 재매핑, 고객센터 데이터 전달 등)

### 숙박세일페스타 비정형 이벤트 — 제한 일정 내 개발·오픈 및 매출 기여

> 한국관광공사 협업 숙박 프로모션 이벤트. 제한된 일정 내 정책 변경까지 반영하여 안정적으로 오픈하고 이후 운영 변경 요청도 신속 대응.

**기간**: 2026년 3월 ~ 7월 (봄편·여름편 총 2회)
**도메인**: MSA - 이벤트

- 쿠폰 발급·사용·관리 API 및 이벤트 화면 개발
- 진행 중 정책 변경사항(관광공사 일정 변동) 실시간 반영
- 행사 연장·배너·이미지 교체 등 운영 요청 신속 대응
- 마케팅담당자, 기획자와 함께 관광공사 측 일정 변동에 따른 정책 변경사항 실시간 반영

**성과 (봄편 기준)**
- 쿠폰 소진율 약 **41.9%** (8,113건 / 19,374건)
- 프로모션 연계 매출 약 **10.6억 원** 달성

## 주요 업무 실적

### 1. 신규 기능 개발

#### 레드페스티벌 비정형 이벤트 개발

- 롯데 유통군 계열사 구매금액 집계 후 일부를 혜택으로 환급하는 비정형 이벤트(BO에서 세팅할 수 있는 이벤트가 아닌 한시적 이벤트 개발)를 단독으로 설계 및 개발
- **오프라인·온라인 주문 데이터 통합** 응모 구조 설계·구현 (이종 시스템 간 주문 정보 통합)
- 응모자 목록 데이터 추출을 위한 파이프라인 구축
- 롯데 그룹차원에서 진행된 이벤트로 그룹 담당자, 사내 마케팅 담당자와 협업을 통한 진행.
- 총 3만명 응모, 1주일간 인입된 50만개 데이터 처리 및 추출

#### 엘스탬프 누적출석미션 개발 및 API 개선

- 엘스탬프 신규 출석미션인 누적출석미션 FO, 어드민의 백엔드, 프런트엔드 개발
- 네이티브 앱과 웹뷰를 위한 호환가능한 API 개발.

#### 엘스탬프 캐릭터 개발

- 스탬프 적립용 스네이크 보드 위의 사용자 맞춤형 캐릭터 영역과 어드민의 백엔드, 프런트엔드 개발.
- 고객의 구매 및 계열사 이용 데이터를 통한 맞춤형 광고 또는 마케팅용 대사가 노출되도록 로직 개발.

### 2. 성능 개선

#### 엘스탬프 미션 조회 API DB 접근 최적화

- 롯데플러스 서비스 내 **TOTAL TIME 최상위 API**로 지목된 미션 조회 API 개선
- GN(구매미션)·RV(리뷰미션) 타입별 스탬프 개수 조회를 개별 호출에서 단일 쿼리로 통합: Read/Write DB 접근 **4회 → 1회** 감소
- 평시 응답속도 약 **30% 개선**, DB 부하 시 쿼리당 500~600ms × 3회 제거로 최대 **1.5초 단축**
- 배포 후 APM 모니터링 Latency 지표 개선 확인

#### 어드민 엘스탬프 미션별 현황 집계페이지 속도 개선

- 엘스탬프 미션별 현황 집계 어드민 페이지 쿼리 및 로직 최적화
- 월말 집계시 **1시간 이상** 소요되던 조회를 **10분 이내**로 개선

#### 구매스탬프 일 대사배치 Timeout 개선

- 데이터 누적에 따라 인덱스가 타지 않는 구조로 월말마다 Timeout 발생하던 대사배치 쿼리 개선
- 개선 전: 평균 **20분**, 최대 **1시간** → 개선 후: 평균 **6분**, 최대 **7분**

### 3. 비용절감

#### 통합DB 레거시 OUT 테이블 제거 (6종)

- 이벤트와 다른 파트의 DB를 통합하며 데이터 복제 테이블 등 총 6종 제거
- 관련 호출부 및 데이터 파이프라인(kafka, CDC 등) 전체 정리

#### 랜덤선택 등의 마케팅 솔루션 어도비 제거

- 어도비 솔루션으로 구현되어있던 엘스탬프 랜덤 리워드 혜택선택 로직 내재화를 통한 비용절감
- 고객별 맞춤으로 혜택이 부여가능하도록 마케팅 구조 개선
  - 블랙 컨슈머 혜택 제거, 오프라인 구매자 온라인 구매 강화 혜택 등

### 4. 안정성 · 보안

#### 이벤트 중복 응모·엘스탬프 미션 중복 참여 방어 Redis 로직 개선

- 이벤트 중복 응모 방어를 위해 Redis와 DB 정합성을 이용한 응모 로직 개선
  - 회원번호가 포함된 Redis 키를 이용하고 회원번호를 포함한 Unique index를 이용하여 순간접속량 및 참여 횟수 제한 통제
- 엘스탬프 미션 중복 참여 방어와 교환소 중복 참여 방어에 AOP를 이용한 동일 패턴 적용하여 시스템 일관성 확보

#### 구매사은 이벤트 어뷰징 방지 정책 개선

- 구매사은 이벤트에서 발생하는 어뷰징 패턴 분석 및 방지 정책 강화
- 부정 당첨 케이스 데이터 추적 및 추출 체계 구축

#### 정보보호 취약점 조치 — 게시판 파라미터 변조 방어

- 취약점 내용: 게시판 이벤트에서 파라미터 변조를 통해 타인의 게시글 강제수정 가능
- 게시글 수정 시 게시물 작성자와 로그인 정보 비교 본인 확인 로직 추가
- 로그인 하지 않고 이벤트번호와 회원번호만으로 응모가 가능한 이벤트 발견. 인가된 사용자만 호출 가능하도록 수정

#### Kafka DLQ 설정 개선 및 pub 로그 강화

- Dead Letter Queue Kafka 설정 개선
- Confluent pub 로그 추가 및 개선으로 메시지 장애 추적 체계 강화

#### 대사배치 Flux→동기 리팩토링 및 알람 체계 개선

- 비동기(Flux) 기반 대사배치 로직을 동기 방식으로 단순화하여 배치 안정성 향상 및 코드 복잡도 감소
- 운영/테스트 슬랙 알람 채널 분리로 장애 인지 속도 개선
- 주문·취소 데이터 동시 유입 시 취소 플래그가 미반영되던 버그 수정

### 6. 협업

#### 코드 리뷰

- 파트 내 동료 코드 리뷰 상시 진행 (리뷰어·리뷰이 양방향)
- 파트 내부의 코드컨벤션, 클린코드 등을 지키고 적용하려 노력
- mcp를 이용한 파트내 ai 코드리뷰 적용

#### 기획·디자인 협업

- 엘스탬프 신규 기능(캐릭터, 누적출석미션 등) 기획자와 협의하며 기획 보조에 적극적으로 참여하여 요건 구체화
- 기획자·디자이너·퍼블리셔와 화면 플로우 조율, 개발 관점의 제약사항 사전 공유로 리스크 최소화

- 롯데멤버스 회원 구매정보 시스템 연동 운영 등 타사 혹은 타 팀과의 데이터·API 인터페이스 사전 협의

## 주요 작업내용

### 측정 가능한 성능 개선
교환소 예산체크·교환 API 집중 최적화로 간헐적 Timeout 완전 제거 및 **평균 응답속도 60% 향상**. 미션 조회 API Read/Write DB 접근 4회→1회 감소, 평시 응답속도 **30% 개선** (DB 부하 시 최대 1.5초 단축). 어드민 집계 페이지 조회 1시간 이상 → **10분 이내** 단축. 구매스탬프 대사배치 월말 Timeout 해결: 평균 20분·최대 1시간 → 평균 **6분·최대 7분**.

### 카프카를 이용한 데이터 파이프라인
Kafka / Confluent Platform 기반 실시간 데이터 수집 파이프라인 운영 경험. JDBC 배치 튜닝, Consumer 파라미터 최적화를 통한 처리 성능 개선 및 DLQ 장애 추적 체계 구축.

### 분산 시스템 동시성 제어
Redis를 활용한 중복 응모/참여 방어 분산 락 구현. 트래픽이 집중되는 이벤트 시스템에서 키 명명 규칙 표준화 및 데이터 정합성 보장. 이벤트·엘스탬프 도메인에 동일 패턴 일관 적용.

### 보안 & 운영 품질
대사 배치 구축 및 리팩토링을 통한 운영 강화. 어뷰징 방지 정책 개선. 모니터링 및 오류알림 강화. 모의해킹 취약점(위험도 상) 대응 경험. 

### 레거시 개선 & 기술 부채 해소
Java 17 업그레이드, 사용하지 않는 코드 및 레거시 테이블 제거 등 대규모 기술 부채 해소 경험. 
대사배치에서 Flux 동작하지 않도록 남발되어있던 코드를 동기적으로 실행되는 리팩토링으로 안정성 향상.
